# Crown Computers CRM + HRM

Современная система управления продажами и персоналом для магазина ноутбуков и компьютеров.

## 🚀 Возможности

### Для всех сотрудников
- ✅ Отметка прихода и ухода
- 📊 Личная статистика и зарплата
- 🏆 Таблица лидеров и достижения
- 📈 Прогресс выполнения плана

### Для менеджеров
- 💼 Добавление продаж
- 📱 Учёт клиентов
- 💰 Отслеживание личной выручки
- 🎯 Контроль выполнения плана
- 📥 **Экспорт продаж в Excel**

### Для операторов
- 📞 Управление лидами
- 🔄 Передача лидов менеджерам
- 📊 Статистика конверсии
- 🎯 Отслеживание эффективности

### Для РОП
- 👥 Управление командой
- 💸 Штрафы и бонусы
- 📋 Установка планов продаж
- 📊 Детальная аналитика
- ⚙️ Настройка зарплат
- 📥 **Экспорт продаж в Excel**

### Для владельца
- 📈 Полная аналитика бизнеса
- 💹 Сравнение периодов
- 🏆 Топ продаваемых моделей
- 💼 Контроль ФОТ
- 👀 Просмотр всех данных
- 👥 **Мониторинг команды в реальном времени**
- 📥 **Экспорт продаж в Excel**

## 🛠 Технологии

- **Frontend:** Next.js 14, React 18, TypeScript
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **Icons:** Lucide React
- **Date handling:** date-fns
- **Excel Export:** xlsx

## 📦 Установка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Запуск продакшен версии
npm start
```

## 🎮 Геймификация

Система достижений мотивирует сотрудников:
- 🏆 **Лучший месяц** - наибольшая сумма продаж
- 🔥 **Без опозданий** - ни одного опоздания за месяц
- 🎯 **Снайпер** - конверсия лидов выше 50%
- 💎 **Топ оператор** - больше всех переданных лидов

## 🚀 Следующие шаги

Система полностью готова к работе! ✅

### ✅ Реализовано:

1. **Backend API** - все endpoints готовы
2. **База данных** - PostgreSQL на Neon подключена
3. **Авторизация** - bcrypt для паролей
4. **Prisma ORM** - для работы с БД
5. **Тестовые данные** - 8 пользователей, продажи, лиды

### 📡 API Endpoints:

- `POST /api/auth/login` - Авторизация
- `GET/POST/DELETE /api/sales` - Управление продажами
- `GET/POST/PUT /api/leads` - Управление лидами
- `GET/POST /api/attendance` - Посещаемость
- `GET /api/statistics` - Статистика пользователя
- `GET/POST /api/plans` - Планы продаж
- `GET/POST/DELETE /api/penalties` - Штрафы и бонусы
- `GET /api/users` - Список пользователей
