## 🔍 Проверка проблем

### 1. Проверьте, что сервер запущен
```bash
npm run dev
```

Должно быть:
```
✓ Ready in X.Xs
- Local: http://localhost:3000
```

### 2. Проверьте базу данных
```bash
npm run db:studio
```

Откроется Prisma Studio - проверьте, что в таблице `users` есть пользователи

### 3. Проверьте консоль браузера
1. Откройте DevTools (F12)
2. Перейдите на вкладку Console
3. Попробуйте войти
4. Посмотрите на ошибки

### 4. Проверьте Network
1. Откройте DevTools (F12)
2. Перейдите на вкладку Network
3. Попробуйте войти
4. Найдите запрос `/api/auth/login`
5. Посмотрите статус и ответ

## ❌ Частые ошибки

### "Неверный логин или пароль"
**Причина:** Неправильные данные или пользователь не существует

**Решение:**
1. Проверьте правильность логина и пароля
2. Убедитесь, что seed выполнен: `npm run db:seed`
3. Проверьте пользователей в Prisma Studio

### "Ошибка соединения с сервером"
**Причина:** Сервер не запущен или база данных недоступна

**Решение:**
1. Запустите сервер: `npm run dev`
2. Проверьте `.env` файл
3. Проверьте подключение к базе данных

### Перенаправляет обратно на вход
**Причина:** Проблема с localStorage или авторизацией

**Решение:**
1. Очистите localStorage в консоли: `localStorage.clear()`
2. Обновите страницу (Ctrl+F5)
3. Попробуйте войти снова

### Белый экран или ошибка
**Причина:** JavaScript ошибка

**Решение:**
1. Откройте консоль (F12)
2. Посмотрите на ошибки
3. Перезапустите сервер

## 🛠 Команды для отладки

### В консоли браузера (F12):

**Проверить localStorage:**
```javascript
console.log(localStorage.getItem('user'))
```

**Очистить localStorage:**
```javascript
localStorage.clear()
```

**Тест API напрямую:**
```javascript
fetch('/api/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ login: 'manager1', password: '123456' })
})
.then(r => r.json())
.then(console.log)
```

### В терминале:

**Перезапустить сервер:**
```bash
# Остановить (Ctrl+C)
# Запустить снова
npm run dev
```

**Пересоздать базу данных:**
```bash
npm run db:push
npm run db:seed
```

**Проверить Prisma Studio:**
```bash
npm run db:studio
```

## 📞 Если ничего не помогло

1. **Остановите сервер** (Ctrl+C)
2. **Очистите кеш:**
   ```bash
   rm -rf .next
   ```
3. **Переустановите зависимости:**
   ```bash
   npm install
   ```
4. **Пересоздайте базу:**
   ```bash
   npm run db:push
   npm run db:seed
   ```
5. **Запустите снова:**
   ```bash
   npm run dev
   ```
