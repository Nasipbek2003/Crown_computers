## 📋 О проекте

Crown Computers CRM - это полнофункциональная система управления для магазина ноутбуков и компьютеров, которая объединяет в себе:
- 💼 **CRM** - управление продажами и клиентами
- 👥 **HRM** - управление персоналом и посещаемостью
- 📊 **Аналитика** - детальная статистика и отчёты
- 📥 **Экспорт** - выгрузка данных в Excel

## 🚀 Быстрый старт

### Требования
- Node.js 18+ 
- PostgreSQL база данных (или Neon)
- npm или yarn

### Установка

1. **Клонируйте репозиторий**
```bash
git clone https://github.com/Nasipbek2003/Crown_computers.git
cd Crown_computers
```

2. **Установите зависимости**
```bash
npm install
```

3. **Настройте базу данных**

Создайте файл `.env` в корне проекта:
```env
DATABASE_URL="postgresql://user:password@host:5432/database?sslmode=require"
```

4. **Примените миграции**
```bash
npx prisma generate
npx prisma db push
```

5. **Заполните тестовыми данными** (опционально)
```bash
npx tsx lib/seed.ts
```

6. **Запустите проект**
```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Тестовые пользователи

После запуска seed скрипта доступны:

## 🌟 Особенности

### Роли и права доступа
Система поддерживает 4 роли с разными уровнями доступа:
- 👑 **OWNER** - полный доступ ко всему
- 👨‍💼 **ROP** - управление командой и аналитика
- 💼 **MANAGER** - продажи и клиенты
- 📞 **OPERATOR** - лиды и первичный контакт

### Автоматизация
- ⏰ Автоматический контроль опозданий (после 09:00)
