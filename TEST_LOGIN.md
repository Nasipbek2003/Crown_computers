## 🔍 Если не работает:

### Проверьте консоль браузера (F12):
1. Откройте DevTools (F12)
2. Перейдите на вкладку Console
3. Попробуйте войти
4. Посмотрите на ошибки

### Проверьте Network (Сеть):
1. Откройте DevTools (F12)
2. Перейдите на вкладку Network
3. Попробуйте войти
4. Найдите запрос к `/api/auth/login`
5. Посмотрите Response (ответ)

### Возможные ошибки:

**"Неверный логин или пароль"**
- Проверьте правильность логина и пароля
- Убедитесь, что используете тестовые данные из seed

**"Ошибка соединения с сервером"**
- Убедитесь, что dev сервер запущен (`npm run dev`)
- Проверьте, что база данных доступна

**Перенаправляет обратно на страницу входа**
- Очистите localStorage: `localStorage.clear()`
- Обновите страницу
- Попробуйте войти снова

## 🛠 Отладка:

### Проверить данные в localStorage:
```javascript
// В консоли браузера (F12)

```

### Очистить localStorage:
```javascript
// В консоли браузера (F12)
localStorage.clear()
```

### Проверить API напрямую:
```javascript
// В консоли браузера (F12)
fetch('/api/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ login: 'manager1', password: '123456' })
})
.then(r => r.json())
.then(console.log)
```
