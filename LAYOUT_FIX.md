# 🔧 Исправление фиксированного меню

## Проблема
При скролле страницы левая панель (Sidebar) уходила вверх вместе с контентом.

## Решение

### 1. Фиксированный Sidebar
```tsx
// components/Sidebar.tsx
<aside className="w-64 bg-crown-navy h-screen flex flex-col fixed left-0 top-0 overflow-y-auto">
```

**Изменения:**
- ✅ Добавлен `fixed` - фиксирует элемент относительно viewport
- ✅ Добавлен `left-0 top-0` - позиционирует в левом верхнем углу
- ✅ Добавлен `h-screen` - высота на весь экран
- ✅ Добавлен `overflow-y-auto` - скролл внутри меню если пунктов много
- ✅ Убран `min-h-screen` - не нужен для fixed элемента

### 2. Отступ для контента
```tsx
// app/dashboard/layout.tsx
<div className="flex-1 flex flex-col ml-64">
```

**Изменения:**
- ✅ Добавлен `ml-64` (margin-left: 256px) - отступ слева равный ширине Sidebar
- ✅ Контент теперь не перекрывается с меню

### 3. Фиксированный Header
```tsx
// components/Header.tsx
<header className="bg-white border-b border-slate-200 px-8 py-4 sticky top-0 z-10">
```

**Изменения:**
- ✅ Добавлен `sticky top-0` - Header остаётся вверху при скролле
- ✅ Добавлен `z-10` - Header поверх контента

### 4. Скроллируемый контент
```tsx
// app/dashboard/layout.tsx
<main className="flex-1 p-8 bg-slate-50 overflow-y-auto">
```

**Изменения:**
- ✅ Добавлен `overflow-y-auto` - скролл только для контента

## Структура layout

```
┌─────────────────────────────────────────┐
│ Sidebar (fixed)  │ Header (sticky)      │
│                  ├──────────────────────┤
│  - Логотип       │                      │
│  - Меню          │  Контент (scrollable)│
│  - Выход         │                      │
│                  │                      │
└─────────────────────────────────────────┘
     256px              flex-1
```

## Поведение

### При скролле вниз:
- ✅ Sidebar остаётся на месте (fixed)
- ✅ Header остаётся вверху (sticky)
- ✅ Скроллится только контент

### При длинном меню:
- ✅ Sidebar получает свой скролл (overflow-y-auto)
- ✅ Логотип и кнопка выхода остаются видимыми (flex-shrink-0)

### На маленьких экранах:
- ⚠️ Sidebar всегда видим (фиксированная ширина 256px)
- 💡 В будущем можно добавить мобильное меню

## CSS классы

### Sidebar
```css
w-64          /* ширина 256px */
h-screen      /* высота 100vh */
fixed         /* фиксированная позиция */
left-0 top-0  /* в левом верхнем углу */
overflow-y-auto /* скролл если нужно */
```

### Content wrapper
```css
ml-64         /* отступ слева 256px */
flex-1        /* занимает оставшееся место */
```

### Header
```css
sticky        /* липкая позиция */
top-0         /* прилипает к верху */
z-10          /* поверх контента */
```

### Main content
```css
overflow-y-auto /* скролл контента */
flex-1          /* занимает всё место */
```

## Преимущества

✅ **Удобная навигация** - меню всегда доступно
✅ **Больше места для контента** - Header не занимает место при скролле
✅ **Профессиональный вид** - как в современных приложениях
✅ **Лучший UX** - не нужно скроллить вверх чтобы переключить раздел
