1. ✅ Frontend на Next.js 14 + TypeScript + Tailwind CSS
2. ✅ Backend API (Next.js API Routes)
3. ✅ База данных PostgreSQL (Neon) подключена
4. ✅ Prisma ORM настроена
5. ✅ Тестовые данные загружены
6. ✅ 8 пользователей с разными ролями
7. ✅ Продажи, лиды, посещаемость

## 🎯 Запуск проекта

### 1. Установка зависимостей (уже выполнено)
```bash
npm install
```

### 2. Настройка базы данных (уже выполнено)
```bash
npm run db:generate  # Генерация Prisma Client
npm run db:push      # Создание таблиц
npm run db:seed      # Загрузка тестовых данных
```

### 3. Запуск приложения
```bash
npm run dev
```

Откройте http://localhost:3000 (или 3001 если 3000 занят)

## 🆕 Регистрация нового пользователя

1. Откройте http://localhost:3000/register
2. Заполните форму регистрации:
   - Полное имя
   - Логин (уникальный)
   - Пароль (минимум 6 символов)
   - Роль (Оператор, Менеджер, РОП, Владелец)
   - Оклад (опционально)
   - Процент от продаж (только для менеджеров)
3. Нажмите "Зарегистрироваться"
4. После успешной регистрации вы будете перенаправлены на страницу входа

## 🗄️ База данных

**Подключение:** Neon PostgreSQL (уже настроено в `.env`)

**Управление:**
```bash
npm run db:studio  # Открыть Prisma Studio (GUI)
```

## 📡 API Endpoints

Все API endpoints доступны по адресу `/api/*`:

- `POST /api/auth/login` - Авторизация
- `GET/POST/DELETE /api/sales` - Продажи
- `GET/POST/PUT /api/leads` - Лиды
- `GET/POST /api/attendance` - Посещаемость
- `GET /api/statistics` - Статистика
- `GET/POST /api/plans` - Планы продаж
- `GET/POST/DELETE /api/penalties` - Штрафы/бонусы
- `GET /api/users` - Пользователи

Подробная документация: `API_DOCUMENTATION.md`
